# Cave

BlackBerry Bold 9900용 Java 게임 프로토타입. For The King을 참고한 헥사맵 탐험과 턴제 전투를 구현 중이다.

## 프로젝트

- `src/`: 지도 생성, 탐험, 파티/장비 능력치, 전투, 마을/조우 화면.
- `res/`: 게임에서 사용하는 이미지. 네 직업 이동은 6방향 × 4프레임이며 100ms마다 프레임을 바꾼다.
- `Cave.jdw`, `Cave.jdp`: BlackBerry JDE 워크스페이스/프로젝트.
- `IMPLEMENTATION_BACKLOG.md`: 구현 상태, 확정한 게임 규칙, 청크별 후속 작업 및 검증 기준. 작업 시 계속 갱신한다.
- `experiments/`: 에셋 제작 프롬프트, 변환 스크립트, 비교 이미지와 복구본. 채택/미채택 여부는 각 README를 확인한다. 실험 파일 전체가 게임에 적용된 것은 아니다.

## 빌드와 확인

서명 키가 필요한 secure API와 deprecated API를 사용하지 않는다. 저장은 표준 MIDP RMS RecordStore를 사용한다. 이전 PersistentStore 저장은 자동 이전하지 않는다.

사용 중인 BlackBerry JDE에서 `Cave.jdw`를 열어 수동 빌드하고 실기기에 설치한다. 최신 변경의 실기기 검증 여부는 작업 기준 문서에 기록한다. 빌드 산출물은 Git에서 제외한다.

## 현재 구현과 에셋 기준

숲 경계 돌출 시험: 숲 바닥140×140은 헥사 안에 그리되 투명 나무 장식120×120은 별도 레이어로 위쪽 최대 약45px 돌출시킨다. 둥근 수관과 짧은 줄기로 산보다 작은 비율을 맞췄다. 공개된 숲 장식끼리 화면 위→아래 순으로 겹치고 캐릭터/커서는 그 위에 표시한다. 원본 숲은 보존했으며 HexRenderer.FOREST_OVERHANG_TRIAL=false로 원래 표시로 돌아갈 수 있다. 최신 제작 기록/산 비교 미리보기는 experiments/forest-overhang-v2에 있다. 실기 검증 대기.

항구는 청록 지붕·밝은 석조 건물의 6방향 전용 타일을 사용한다. 인접한 물 방향 중 반경3의 연결 수역이 넓게 트인 쪽으로 부두·배를 향하게 선택한다. 지도 생성/로드 때 방향을 캐시하고 렌더링에서는 해당 이미지만 사용한다. 기존 PORT 글자는 제거했으며 미니맵 항구는 청록색을 유지한다. 제작 원본/프롬프트/헥사 비교는 experiments/port-tiles-v2에 보관했다.

C16c 항해: 새 게임은 기존 첫 마을을 유지하고 별도 항구2곳과 수로를 생성한다. 지도 PORT/미니맵 청록색 마을에서 생존자 최소2명이 모여 Sailing / Choose Passengers로 인원을 선택한다. 구매 비용 없이 승선하며 현재 캐릭터가 조종한다. 물/항구 경로는 기존 미리보기→확정 이동을 사용하고 조종자의 이동력만 타일당1 소비한다. Space 뒤 다른 승객의 차례에는 그 승객이 조종할 수 있다. 항구 도착 후 Disembark passengers로 해당 배의 전원이 하선한다. 바다 조우는 없고 다른 해안에서는 하선하지 못한다. 항해 그룹/위치는 저장되며 v1 저장도 읽지만 기존 지도에는 항구를 소급 생성하지 않는다. 첫 항해 테스트는 새 게임으로 한다.

C16b6 나머지 직업 고유 특성: Thief는 맵 도망/전투 도주 기본 개별 성공률+10%p(상한90%, 기습 제외), Mage는 Focus를 쓴 공격에서 모든 칸이 성공하면1 반환(전체 공격도1회), Nun은 장착 회복 무기의 회복력+4. Focus 보정과 최대치 제한은 유지하고 회복초/부활에는 치유 특성이 적용되지 않는다. 전투/필드 수녀 최대 회복은 INT80에서16이다.

C16b5 전사 고유 특성: 직접 공격의 성공 수 비례 피해를 계산한 뒤 1 감소한다(최소0). 장비·도발 여부와 관계없이 적용되며 출혈 같은 지속 피해는 감소시키지 않는다. 기존 저장의 전사에도 적용된다.

직업 능력치 조정(2026-09-30): 시작 장비 포함 Warrior HP40/STR82/INT35/이동4/Focus3, Thief 22/75/50/8/3, Mage 18/30/84/5/4, Nun 26/40/80/5/5. 레벨당 HP는 각각 +4/+2/+2/+3, Warrior·Thief STR+1, Mage·Nun INT+1, 전원 피해+1이다. 능력치 상한95, 이동·최대 Focus·보조 능력치는 레벨로 증가하지 않으며 현재 HP·Focus/KO를 유지한다. 기존 저장의 기본 수치를 보존하고 다음 레벨업부터 새 성장량을 적용한다.

C16b4 적 대상 선택: 슬라임은 무작위, 늑대는 남은 HP 비율이 가장 낮은 아군, 고블린·고블린 대장은 자신을 마지막으로 공격한 생존 아군을 공격한다. 동률·유효한 공격자 없음은 무작위이며 도발이 항상 우선한다. 공격이 모두 실패해도 공격자 기록은 갱신하며 전체 공격은 각 적에게 기록한다. 기록은 전투 종료 시 제거한다.

C16b3 Dagger의 Bleeding Cut은 STR3칸 성공 수에 비례한 일반 공격50% 즉시 피해와, 2칸 이상 성공 시 출혈을 준다. 출혈은 대상의 다음 두 차례 시작에3HP씩 감소하며 재적용은 횟수만 갱신한다. 출혈 KO 대상은 행동하지 않고 전투 종료 후 효과는 남지 않는다. 공통 Actions 메뉴에서 선택한다.

C16b2 Magic Staff 장착자는 Actions 메뉴의 Arcane Wave로 생존 적 전원을 공격한다. INT3칸을 한 번 굴리고 적별 최대 피해는 일반 공격의50% 내림, 실제 피해는 성공 수에 비례한다. 선택 Focus를 지원하며 실패해도 행동을 소비한다.

전투는 공통 Actions 메뉴에서 Attack/Heal/Taunt/Flee를 이름으로 선택한다. 장착 장비가 제공하는 행동만 표시하며 보스전에는 Flee가 없다. 키/트랙패드로 메뉴를 이동하고 Enter/클릭 또는 항목 터치로 선택한다. 행동별 H/T/F 단축키는 사용하지 않는다.

C16b1 Plate Armor 장착자는 전투 행동 메뉴에서 Taunt를 선택해 자신에게 도발을 걸 수 있다. STR 3칸 중2개 이상 성공하면 다음 자기 차례 시작까지 적의 단일 공격을 자신에게 집중시킨다. 선택 Focus를 지원하고 실패해도 행동을 소비한다. 피해 감소는 없으며 KO되면 대상 강제가 사라진다. 전투 종료 후 효과는 남지 않는다.

C16a 새 게임 수녀는 Healing Staff로 시작한다. 전투 행동 메뉴에서 Heal, 필드에서 I→Heal target with equipped weapon으로 자신 또는 아군 한 명을 회복한다. 전투 참가자/필드 같은 타일만 대상이며 KO는 제외한다. 최대 회복량은 (무기 회복력16+치유 숙련4)×최종 INT/100, 실제량은 INT 주사위 3칸 성공 수에 비례한다. Focus는 선택 투입이고 실패해도 행동/턴이 종료된다. 이전 저장에는 시작 무기를 자동 추가하지 않으므로 첫 테스트는 새 게임으로 한다.

C15에서 이동과 미니맵 페이드가 끝나면 월드 타이머를 멈추고, 입력이나 화면 복귀 시 필요한 경우 다시 시작하도록 했다. 미니맵 투명도가 유지되는 동안 불필요한 화면 갱신도 줄였다. 이동 속도·보행·게임 규칙은 유지하며 실기 성능·장시간 테스트는 대기한다.

C14에서 시작 화면 New Game/Continue와 저장 3슬롯을 추가했다. 지도에서 BlackBerry 메뉴의 Save Game으로 슬롯을 선택해 저장하며, 정상 종료는 현재 슬롯에 자동 저장한다. 이동·전투·조우 중에는 저장할 수 없다. 개인 자원·가방·장비, 지도·적, 월드 턴 순서와 퀘스트를 복구한다. 강제 종료 시에는 마지막 저장에서 이어지며, 향후 랜덤 판정은 별도 시드로 시작한다. 사용자 수동 빌드·실기기 검증 대기다.

C09에서 지도 트랙패드 클릭/터치 탭을 경로 미리보기·이동에 연결하고, Back 단계별 취소·종료 확인과 전투 트랙패드/터치 조작을 추가했다. 드래그는 지도 패닝만 수행한다. C09는 사용자 정상 동작 보고를 받았다. C10 변경 후 입력 회귀 확인은 대기한다.

C12 상점은 실제 마을 방문자의 개인 골드로 회복초(10G)·부활초(40G)를 구매하고, 가방의 초를 각각 5G·20G에 판매한다. 시작 장비는 현재 상점에서 판매할 수 없다.

C13 첫 퀘스트는 첫 마을에서 수락한 뒤 지도 적 전투 3회 승리·보고로 진행된다. 보고하면 도보로 접근 가능한 고블린 대장 타일 하나가 공개된다. 생존 파티 전원이 대장 근처에 모이면 전투를 선택할 수 있고, 처치하면 추가 60G·40XP와 캠페인 승리 화면을 받는다. 현재 실기 검증 전이다.

C11에서 지도 I/마을 Inventory로 개인 12칸 가방, 장비 교체·이전과 부활초 사용을 연결했다. 각자 부활초 1개로 시작하며 같은 필드 타일의 KO 동료를 살리면 사용자 턴이 끝난다. 전투 드롭은 C12 이후로 보류했다.

C10에서 실제 화면 크기에 맞춘 카메라·전투 배치, HUD Focus 아이콘 크기, 공개 지형과 마을·적·파티·커서 미니맵 표시를 수정했다. 전투 터치 영역은 새 배치와 동일한 계산을 사용한다. 리소스 원본은 유지하며 실기기 화면 확인 대기다.

C07에서 승리 보상·레벨 성장을 구현했다. 골드는 캐릭터별로 소유하며 월드에서 G를 눌러 같은 타일의 동료에게 이전한다. 상세 규칙과 실기기 확인 항목은 `IMPLEMENTATION_BACKLOG.md`를 따른다.

C08 여관은 같은 마을의 생존 캐릭터가 본인 골드 레벨×5를 지불해 HP·Focus를 회복한다. 턴·이동력은 유지하며 KO는 회복하지 않는다. 마을 타일에서 Enter로 재입장할 수 있다. 부활초 사용은 인벤토리 청크에 연결할 예정이다.

사용자가 선택한 초기 4프레임 보행을 유지한다. 수녀 NE/NW는 다리 교차 보정본을 사용한다. 전사는 발 색상만 금속색으로 수정한 Git 저장본(6280d85)을 사용한다. 얼굴 확대·다리 단축 시도는 거절하여 모두 되돌렸다. 이전 얼굴/투구 부분 수정 시안도 게임에는 적용하지 않았다.

숲 점유 전환: 빈 숲은 밀집 나무, 파티원(KO 포함)이 있는 숲은 중앙이 열린 나무/덤불 레이어로 약0.5초 교차 전환한다. 새 레이어140×190은 하단 덤불도 헥사 밖에서 온전히 그린다. 기존 UI 타이머를 사용하며 점유·전환은 저장 데이터 변경 없이 재구성한다. 최신 에셋/실제 파티 배치 미리보기/검증 항목은 experiments/forest-occupancy-v1. 실기 검증 대기.

산 봉우리 돌출: 산 바닥140×140과 투명 봉우리140×190을 분리, 중심(-70,-125) 배치로 헥사 위쪽에 표시한다. 숲/산 장식은 함께 깊이 정렬하며 원본 산·통행 규칙은 유지한다. 최신 미리보기/기록은 experiments/mountain-overhang-v1. 실기 검증 대기.

최신 지형 표시(2026-10-01): 숲은 기존 밀집/열린 모양·배치·전환을 유지하며 밝기만10% 낮춤. 산 봉우리는140×210·중심(-70,-140)으로 높이/대비 강화. 승인 미리보기와 기록은 experiments/terrain-balance-v1/preview_dark_forest.png 및 README.md. 실기 검증 대기.
