# 도적 6방향 걷기 시험

상태: IMPLEMENTED_UNVERIFIED. 사용자 수동 빌드·실기기 평가 대기. 전사 걷기 유지.

- 도적 원본 thief.png의 검은 후드/복장, 갈색 장갑·장화, 단검 스타일로 제작.
- res/thief_walk_trial.png: 420×280 투명 PNG, 70×70 셀, 6방향×4프레임.
- 열: E(+1,0), NE(+1,-1), NW(0,-1), W(-1,0), SW(-1,+1), SE(0,+1).
- 행: 접지/다리 교차/반대발 접지/반대 교차. 기존 전사와 같은 100ms 프레임 교대(한 순환400ms).
- 원본 도적의 가시 높이48px/발 기준선57px에 맞춰 생성 시트 행을 분리·동일 비율로 축소 정렬. prepare.ps1에 준비 및 투명 경계 검사 저장.
- built-in image_gen 도구 사용. 원본 도적은 캐릭터 참조, 전사 시트는 방향/걷기 구조 참조. 프롬프트는 PROMPTS.md, 고해상도 채택 시트는 generated-atlas.png.
- Unit의 기존 공통 이동 방향/프레임 코드 사용. 이동 중에만 atlas 표시, 정지/전투/HUD는 원본. Mage/Nun/몬스터 변경 없음.
- 검증: 24프레임 모두 비어 있지 않고 경계 투명, PNG 크기·소스 구조/인코딩·JDP 등록 확인. 원본 도적/전사 해시 보존 확인. 게임 빌드/실행은 하지 않음.

## 실기기 테스트

1. 새 게임 첫 활성 캐릭터 Thief로 이동한다.
2. 6방향 및 꺾이는 경로에서 방향과 양발 교차를 확인한다.
3. 전사와 함께 비교해 정지 시 크기 변화/걷는 중 흔들림/발 잘림 여부를 확인한다.
4. 조우 도망 후 경로 재개, 전투/마을 진입 및 백그라운드 복귀를 확인한다.

## 도적만 되돌리기

Unit.java의 THIEF_WALK_TRIAL=false로 빠르게 비활성화. 전사 플래그는 유지한다.
변경 전 Unit.java/Cave.jdp 및 원본 도적은 before에 보관(승인된 전사 적용 포함). 이후 작업이 있다면 전체 덮어쓰기를 피하고 도적 변경만 선택적으로 revert한다. 원본 도적 PNG는 수정하지 않았다.
