# 숲 경계 돌출 시험 — 2026-10-01

APPLIED_UNVERIFIED. 빌드·실기 검증은 사용자 수행 대기.

기존 tile_forest.png를 스타일 기준으로 built-in image_gen으로 새 바닥과 투명 나무 장식을 생성했다. 원본 숲/다른 지형/캐릭터 이미지는 변경하지 않았다. 프롬프트/생성 파일 경로는 generation.json, 원본은 *_source.png, 축소 재현은 export.ps1, 지도 배치 미리보기 재현은 preview.ps1이다.

- tile_forest_floor.png: 140×140, 헥사에 잘라 그리는 숲 바닥.
- forest_trees_overlay.png: 140×180, 알파 투명 나무3그루 장식. 타일 중심 기준 (-70,-115)에 배치하여 위로 약40px 돌출.
- preview_map.png: 같은 위치/크기/레이어 순서로 구성한 2배 확대 미리보기. BlackBerry 실행 화면은 아니다.

HexRenderer.prepareTerrain은 지도 생성/로드 후 숲 타일을 r/q 순서로 한 번 정렬한다. 매 프레임은 공개된 숲과 화면에 걸치는 장식만 그린다. 바닥/경계/이동범위/경로 → 숲 장식 → 유닛 → 커서/HUD 순서다. 장식끼리는 위에서 아래 순서로 겹치고, 시험 단계에서 캐릭터는 나무 위에 그려 항상 보이게 한다. 안개 공개 여부는 그릴 때 확인한다. 장식이 공개된 타일의 바깥으로 뻗는 것은 허용하지만 미공개 숲 자체는 숨긴다.

원래 숲으로 되돌릴 때는 HexRenderer.FOREST_OVERHANG_TRIAL을 false로 바꾸면 된다. 저장/게임 규칙/타이머는 변경하지 않았다.

후속: 실기에서 숲 밀집 구역의 경계/돌출 높이/캐릭터·커서·경로 가시성/스크롤 속도/안개 확인. 만족하면 산 봉우리, 도시·항구 건물에 같은 바닥/장식 분리를 적용한다. 유닛과 장식의 완전한 앞뒤 깊이 합성은 이번 시험에 포함하지 않는다.
