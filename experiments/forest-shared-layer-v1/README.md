# 동일한 주변 숲을 공유하는 시안

PREVIEW_ONLY. 기존 게임 코드와 res는 변경하지 않았다.

두 상태를 독립적으로 생성하는 방식을 폐기한다. 공통 forest_surround.png는 동일한 위치·크기로 항상 표시하고, 빈 타일에서만 중앙 forest_center.png를 뒤에 추가한다. 주변 숲은 두 상태에서 같은 파일을 사용하므로 형태·색·위치가 같다. 진입 시 중앙 레이어만 알파를 낮추고 이탈 시 높이는 방식으로 적용할 예정.

built-in image_gen으로 이전 밀집 숲을 참조하여 주변 레이어와 중앙 추가 레이어 생성. *_source.png 보존, export.ps1 축소, preview.ps1 실제 파티 오프셋 비교. 미리보기는 PC 구성 이미지다. 하단 덤불과 숲 상단 돌출 유지.

후속: 시안 확정 후 게임에 공통 주변 레이어+중앙 알파 전환 적용. 낮은 숲·높은 산 비율도 함께 적용하고 실기 검증.
