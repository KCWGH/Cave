# 숲 장식 크기·수관 수정

APPLIED_UNVERIFIED. 사용자 수동 빌드·실기 평가 대기.

원본 숲을 스타일 기준으로 built-in image_gen에서 둥글고 촘촘한 수관을 새로 생성했다. v1의 긴 나무와 뿌리를 줄이고 투명 장식을 140×180에서 120×120으로 축소했다. 투명 여백을 제거한 뒤 비율을 유지하여 내보내며, 게임 배치는 중심 기준 (-60,-115), 상단 돌출 최대 약45px이다. 숲 바닥과 원본 지형은 유지한다.

generation.json에 프롬프트·생성 원본 경로, export.ps1에 축소 과정, preview.ps1에 산·숲·전사를 함께 놓은 2배 확대 비교가 있다. preview_map.png는 PC 구성 미리보기이며 실기 화면이 아니다. v1 파일은 비교·복구용으로 보존한다.

후속: 실기에서 산과의 크기 균형, 밀집 숲·안개·스크롤·캐릭터 가시성 확인 후 산 장식 분리를 진행한다.
