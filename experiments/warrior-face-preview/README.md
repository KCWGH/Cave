# 전사 얼굴 / 투구 부분 수정 시안

상태: PREVIEW_ONLY. 게임에 미적용. 사용자가 복원한 현재 보행을 기준으로 얼굴·표면 디테일만 수정하는 방법을 평가한다. 다른 직업은 변경하지 않는다.

후속 발 금속색 보정은 ../warrior-metal-feet에 기록했다. 현재 warrior-before.png 및 얼굴 후보/비교 이미지에도 금속색 발 보정을 반영했다. 얼굴·투구 시안 자체는 여전히 게임에 미적용이다.

내장 image_gen으로 현재 전사 고해상도 atlas를 편집하고 원본 idle 확대본을 얼굴·금속 명암 참조로 사용했다. 전체 프롬프트는 PROMPT.md, 출력은 generated.png에 보관했다. generated.png 전체를 게임에 적용하지 않는다.

prepare.ps1은 기존과 같은 셀 정렬 후 투구의 기존 회색 픽셀 표면과 기존 얼굴 범위에만 같은 좌표의 색을 통합한다. 얼굴을 늘리거나 줄이지 않는다. alpha는 전부 원본 값을 유지한다. 결과 warrior-candidate.png에서 변경된 2752픽셀 모두 셀 y36 미만이며, 몸통·다리·발의 픽셀과 전체 윤곽은 기존과 동일함을 검사했다.

comparison.png: 원본 idle / 현재 걷기 / 부분 수정 시안, 게임 규격70×70을 4배 확대. 얼굴의 면적이 작아 차이는 작으며, 원본 얼굴과의 시각 일치가 승인된 것은 아니다. 게임 적용·빌드·실행 없음. warrior-before.png는 현재 보행 기준의 사본이며 res/warrior_walk_trial.png와 해시 일치 확인.
